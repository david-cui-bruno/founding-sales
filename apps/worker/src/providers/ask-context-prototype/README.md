## Verdict

**Do not integrate this compact view on the present evidence.** It reduced input, but both arms were conservatively useful without material correction in6/12 generations. The representation improved ambiguous-opportunity/maintenance outputs and worsened shared-address/historical-promise attribution. Every reply-coverage result still promoted note-reported limits into actual corpus coverage. Static instructions and all eight tool definitions stayed fixed; this does not settle whether a different, fully aligned compact architecture would help.
