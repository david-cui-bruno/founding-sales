The concrete contract limitation

Current claims require an original citation even for a SQL-only answer. Exact results remain visible separately. The proposed unified references can express an exact-only sentence. This is a grammar difference; neither grammar proves semantic support.

The model would draft responsive prose and references. The host still owns admissible evidence, current access, actual coverage, exact state, deletion/cancellation, tool execution, spending and publication. Source body text cannot authenticate itself.

Before any production contract change
Specify a versioned result with compatible readers/history and explicit source-only/exact-only/mixed behavior. Verify whole-input deletion/access closure, current exact authority, cancellation and conserved spending through existing authenticated reads and registered workers. Measure actual provider usefulness separately. No mandatory extra generation, framework or relational schema migration is justified by this review.
Release hold and sending safeguards remain. No activation follows from the demo.
