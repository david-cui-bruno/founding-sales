## Chosen next experiment

Test the minimal design's concise authority-preserving instructions alone. Messages, evidence, tools, tool choice, strict output grammar, model, disabled thinking, output ceiling and existing host controls stay fixed. The text has general rules, not fixture-specific names, dates or expected answers. Six familiar development cases with one paired sample per arm are a narrow diagnostic, not held-out evaluation or representative quality. Do not integrate on a higher aggregate score if coverage, attribution or historical commitment failures remain.

## Output contract finding

The present agent grammar and host candidate guard require at least one original citation per Claim. Exact observations remain separately displayed; SQL-only prose cannot be expressed naturally without borrowing an irrelevant original. This is an expressiveness limitation, not a proven cause of current failures. The current mixed claims can cite actual exact observations, but membership alone cannot establish each clause's support.

A later separate contract prototype can examine natural answer blocks with a unified host-minted evidence-reference list. Only admitted originals, executed exact queries and genuine server-owned coverage could mint their respective handles. The host must preserve whole-input access/deletion closure even for source-free exact prose, history reader compatibility, cancellation/fencing and financial accounting. Every model interpretation remains cited_unverified. Neither a unified refs array nor a basis tag proves entailment; a declared inference can still contain an unsupported fact.

The alternative requires explicit versioned result compatibility work and appropriate public/registered-worker regressions before integration. It does not automatically require a database migration, another model call or a remote verifier. Keep this distinct from the instructions experiment.

## Responsibility

Host: admissible sources/current access, scope, SQL exact state, actual coverage metadata, tool execution, deletion/cancellation, spending and publication. Model: responsive synthesis, interpretation and supported uncertainty from the supplied evidence. Source text cannot authenticate itself or mint authority. Counts/absence establish only the actual queried state, not real-world promise currency or complete channel history. Release and sending safeguards stay independent.
