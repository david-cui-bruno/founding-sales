# ADR 0020: Browser private social review

Accepted October 24, 2026. First finite browser slice of the approved review-first social outcome.

Reuse existing social suggestion contracts and owners through exact POST reads `/social/drafts` and `/social/drafts/read`. Preserve workspace/owner scoping, current source revalidation and current authenticated principal after waits. No new social mutation is admitted by the browser boundary.

The owner can inspect retained source metadata, approved factual inputs and existing ready suggestions, and compose a post or comment privately. Re-read a selected request before adopting a variant. Provenance is not semantic support. Changed, unavailable, review or expired requests cannot supply an adoptable variant. Edits are unverified and require human review.

Composer text exists only in authenticated mounted session memory, never local/session storage, command receipts, post revisions or jobs. Explicit discard and session/client/workspace/device/role invalidation clear it and all private projections. Refresh loses edits. The screen states that drafts are not saved, approved, scheduled or published. An empty suggestion workspace still permits manual private composition.

No generation request, provider activation, paid source acquisition, post save/approval/cancellation, account configuration, weekly setting, asset mutation, manual handoff, delivery or LinkedIn action is exposed. Existing delivery and unknown-result machinery is unchanged. Model-backed generation, durable drafts, sourced comment generation and editable private voice learning remain follow-on outcomes, not claims of this slice.

Acceptance exercises existing reads, current source and principal fences, memory-only edits and invalidation, strict negative route boundaries and no outbound/job/post/approval writes through the actual signed browser stack with controlled retained fixtures. It does not claim production source coverage or live model execution.
