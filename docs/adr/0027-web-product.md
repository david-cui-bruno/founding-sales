# Web is the product

David's October28 direction retires the desktop application and its fallback role. Build web selling journeys from the user's goal, rather than porting native screens or preserving them for parity. This supersedes the desktop-product assumptions in ADR0012/0017 and older PLAN entries; their authentication, private-data, consent and execution safeguards remain.

Delete desktop source, packaging, update publishing and obsolete-only tests. Give actual web consumers web ownership and remove IPC fallback; shared domain rules and server authority remain. Missing web owner setup or CRM preparation is a web product gap, never a prerequisite to reopen desktop. Preserve historical database/UNKNOWN records, client-version refusal contracts and [retained signed artifacts](../operations/retained-client-artifacts.md) until their explicit operational retirement. Product retirement grants no data deletion, provider activation, acquisition, contact or spending authority.
