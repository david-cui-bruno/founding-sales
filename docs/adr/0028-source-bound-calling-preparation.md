# Source-bound company preparation for Calling

Accepted design and closed interface for #820. A current kept company-phone choice can explicitly create an unqualified Firm for the existing call engine, with a research-only hold installed before normal enqueue. A second candidate-call subject would duplicate route, cadence, session, reservation and outcome policy; silently promoting the choice would falsely turn temporary source evidence into independent CRM authority. Dated implementation, release and activation status belongs in current-state.

The preparation owns its exact source-derived profile and route, retains a durable source/choice/revision binding, and grants no qualification, consent or call eligibility. Ordinary edits cannot launder those owned fields; only explicit review of the same current choice can replace a live preparation. Changed or cleared choice, lost source/creator rights, deletion or expiry withdraws it without automatic rebind or resurrection. Existing independently recorded Firms, including3G, are opened explicitly and remain independent of this lifecycle.

An actual wrong-number outcome may retire its exact route through the existing outcome owner as a restrictive fact. This preserves source ownership and aligned route/preparation versions; later profile review cannot revive eligibility. It adds no ordinary edit or restore entitlement. Source loss stops execution without discarding independently authored actual history, including a later outcome report.

Current company and Today reads explicitly negotiate a server-derived original source deadline; legacy and independent records omit it. Loaded web views remove owned fields at that deadline and reject already-expired responses before display, preserving independent contacts/history and UNKNOWN custody. Fresh reads revalidate remote changes; this is no real-time remote purge service. Source and principal custody must both survive final publication waits.

An erased endpoint cannot receive a new handle suppression, but an honest outcome correction and explicitly requested independent Firm stop remain possible with an unavailable-route notice. A late retained handoff outcome may link only the original source-erased preparation, actor, Firm and terminal route through opaque identities, without restoring frozen context or endpoint/proof. Whole-Firm deletion remains excluded. An immutable recorded-outcome fact preserves once-only denial even after erasure clears the history link.

Withdrawal removes current phone execution/projections immediately; source erasure physically clears owned fields and endpoint copies. Erased routes and tickets retain opaque identities with one-way nonactionable tombstones so provider, charge, cadence and UNKNOWN history survives without retaining the source literal. Retire-only leaves copies visible and whole-Firm deletion destroys unrelated history; neither is source-only erasure. Original receipt recovery returns historical IDs and requires a fresh current read. Existing eligibility, owner, source, cap, hold, hours and explicit media/contact gates remain additional requirements. The [October28 browser policy](../sourcing/founder-actions/dnc-registration.md) removes blanket registry-download/clearance admission, while preserving known matches and internal do-not-call restrictions; the closed iPhone lane is unchanged.

Reviewed-US confirmation is explicit; unknown country can preview but cannot inherit a default. Erased profile country uses reserved `ZZ` meaning unavailable while preserving existing string DTOs; precise location/zone fields are cleared. Dialing does not check country, so every execution path must enforce terminal preparation/current-source refusal and retired/NULL endpoint. Erasure constraints must cover every marked counterpart and reject a state-only tombstone that leaves owned bytes. Known committed duplicate matches refuse preparation; exact-candidate uniqueness survives forever, without claiming global entity resolution against independent concurrent creation.
