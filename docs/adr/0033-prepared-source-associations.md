# Retain actual redirect provenance for prepared research

The bounded Step1.2.2 audit found that source permission groups path-slash variants while original attribution requires exact URLs. Similar URLs cannot prove that the same resource was captured, and widening the shared authority resolver would also change phone research. New qualification requests therefore pin a separate `prepared-source-association-v1` capture policy; old and queued requests retain the legacy default.

The opt-in adapter records actual initial/redirect/final page requests after its existing URL, DNS, robots and current-authority checks. Qualification stores a separate immutable manifest binding exact candidate/revision/source URL and observation IDs, hashes and retrieval times. This metadata never enters shared observations or model input. Producer/prompt/policy versions, job payloads and same-day paid fingerprints remain unchanged. The manifest is first stored atomically at terminal completion when validated originals survive; replacing or erasing originals clears it, and a completed capture cannot be reopened to restore it.

This first policy accepts only an actually followed same-origin single trailing-slash redirect from the exact ordinary candidate source. Prepared research alone consumes that association. Every accepted dependency has the same existing conservative source-loss/expiry key; current candidate/run/evidence locks, repeated source/manifest/principal checks, earliest expiry and publication deadlines remain. A manifest is not an enduring retention license or contact permission. The shared phone, native, canonical and email granting rules remain exact.

Arbitrary redirects, host aliases, auxiliary pages, root normalization without a trace and historical path equivalence receive no new grant. Their provenance cannot be reconstructed from host membership or by trimming stored URLs. Complete-page and substantive-business/contrary checks remain. Partial pages and independent extraction fields are separate future work. Controlled acceptance establishes the changed handoff; protected delivery and genuinely new ordinary useful output establish deployment and value separately under unchanged budgets, pacing, stored email OFF and paused schedules.
