# Retain actual redirect provenance for prepared research

The bounded Step1.2.2 audit found that source permission groups path-slash variants while original attribution requires exact URLs. Similar URLs cannot prove that the same resource was captured, and widening the shared authority resolver would also change phone research. Qualification requests pin a separate capture policy. Legacy and already queued requests retain their recorded policy; v1 and v2 have distinct immutable interpretations.

The opt-in adapter records actual initial/redirect/final page requests after its existing URL, DNS, robots and current-authority checks. Qualification stores a separate immutable manifest binding exact candidate/revision/source URL and observation IDs, hashes and retrieval times. This metadata never enters shared observations or model input. Producer/prompt/policy versions, job payloads and same-day paid fingerprints remain unchanged. The manifest is first stored atomically at terminal completion when validated originals survive; replacing or erasing originals clears it, and a completed capture cannot be reopened to restore it.

V1 accepts only an actually followed same-origin single trailing-slash redirect from the exact ordinary candidate source; its stored and queued behavior remains unchanged. Prepared research alone consumes that association. Every accepted dependency has the same existing conservative source-loss/expiry key; current candidate/run/evidence locks, repeated source/manifest/principal checks, earliest expiry and publication deadlines remain. A manifest is not an enduring retention license or contact permission. The shared phone, native, canonical and email granting rules remain exact.

V2 preserves an actually followed bounded HTTPS redirect from that exact candidate source to a page on the same research site, including its existing bare/www alias and path redirects. Every hop must pass the existing URL, DNS, robots and current-source checks. The manifest binds the exact observed sequence, final page hashes, retrieval time and observation ID; host membership alone, untraced auxiliary pages and historical path equivalence remain insufficient. This changes metadata retained from an already authorized ordinary capture, not its requests, model input, producer, prompt, paid fingerprint, budgets or pacing.

Prepared research alone receives v2 grants after current candidate/run/source validation. Every hop and final URL has its own existing denial/retention group; one lost dependency refuses the association and the earliest expiry bounds the whole derived read. Initial evidence locks share the existing global ordering before principal waits, and all dependencies are rechecked after waits. Source erasure clears affected v2 provenance; shared exact original/phone/native/email authorities are not broadened. Old missing traces cannot be reconstructed or backfilled. A record without a permitted source stays unresolved until genuinely new authorized ordinary input supplies one.

Partial-page interpretation is separately disclosed by ADR0032 and grants no company authorship, verified fit or contact permission. Controlled acceptance establishes each changed handoff; protected delivery and actual useful output establish deployment and value separately. Email stays OFF and paused schedules stay paused; no historical capture, model diagnostic or same-day paid attempt is replayed.
