Accepted design November4,2026; implementation is not yet deployed. The [agreed personal-brand workflow](../greenfield/founder-social-publishing.md) amends only the private-only/automatic-publication exclusions in [ADR0020](0020-browser-private-social-review.md), [ADR0021](0021-durable-private-social-composition.md) and [ADR0022](0022-private-social-voice-preferences.md): explicitly public-safe current owner notes can support three distinct privately reviewed calibration drafts, followed by separately granted scheduled generation and publication on one exact personal LinkedIn account. Saving a note/guide, accepting calibration, connecting an account, historical recurring approval and runtime availability grant none of those other authorities. Preserve current-only erasure, opaque calibration references, system-worker actors, existing model budgets, three owner-local weekly slots across revisions/reconnects and durable markers before any possible remote write; uncertain outcomes are inspected, never recreated. Pause requests authorized future-schedule cancellation without claiming that publication cannot win the race.

Actual default-security ARM64 Fargate rejected sandboxed Chromium. David approved approximately$20/month for one browser-only EC2 host; finite native confinement and authenticated six-client/firewall/shutdown acceptance passed without host capabilities or a sandbox-disabling fallback. Keep API/worker/DB/provider credentials on Fargate, use a separate authenticated control token behind the existing TLS edge, and retain only encrypted owner-bound cookies in PostgreSQL. The host receives neither the session encryption key nor application credentials; container egress blocks IMDS/private services. Six bounded control connections preserve existing two-API/one-worker rolling deployment, not six browser hosts. [Hosting evidence and limits](../greenfield/social-publisher-runtime-hosting-20261104.md) owns the exact profile; actual protected production TLS/secret/log delivery remains separate.

The [official API alternative](../greenfield/social-linkedin-publication-options-20261103.md) documents member creation but does not establish this application's restricted reads, image readiness or unattended unknown-outcome reconciliation. Do not silently replace the accepted workflow with manual-only publishing or weaken the sandbox. Credits currently offset EC2, but remaining funding/expiry is unknown; the approved budget is not a free-hosting claim. Genuine owner voice, account connection and exact live plan/content/media/cadence activation remain operational inputs, not engineering test actions.
