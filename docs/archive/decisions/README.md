# Decisions

**Archived on 26 September 2026.** These are the decision records written while FSS was built, moved here from `docs/decisions/`. A new decision is recorded in the pull request that makes it; a safety rule (anything that decides whether the product sends, dials, deletes, restores or deploys) is also written into the document of the part it governs under `docs/greenfield/`.

The documents written before that date are history. They stay as they were written: code and other documents cite them, and a later document or changelog line supersedes one rather than editing it.
