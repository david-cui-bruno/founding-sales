# Action-focused Today — #446

The approved TDD seams are the public domain action read/open interfaces against real local PostgreSQL (including existing mail ingestion with a controlled Gmail adapter), the API dispatcher with authenticated workspace sessions, and the public TodayWorkspace UI through the controlled Operations adapter. Domain tests catch current source/ownership/resolution and durable identity; dispatcher tests catch authenticated routing and validation; UI tests catch exact context navigation, quiet healthy work and honest unavailable state. They do not establish provider delivery, production release or signed desktop publication.

Actions are a live, versioned read separate from the legacy daily/cached firm list. Their identity is the source identity, never the regenerated today_items.id. Metadata contains no reply body, excerpt, generated draft or recipient address. Current source state is authoritative: answered/resolved/reassigned/cancelled sources no longer offer the old action. A meeting link also binds its current start, so a reschedule invalidates an old target.

Opening is a current-state read and navigation acknowledgement only. No viewed/delivery receipt is persisted, and acknowledgement never completes, hides or resets unanswered/overdue work. Future notifications (#447) must consume the same current read and own their durable delivery/acknowledgement receipts separately. Reply overdue uses one business day in the workspace business timezone and current workspace holiday calendar.

Today prioritizes overdue replies, substantive replies, upcoming booked calls within seven days, and actionable problems. Healthy routine progress has no action. Empty and unavailable are distinct. No recipient approvals, notifications, sends or generated drafts are added. Source completion is separate from backend deployment and signed desktop publication.

The reply source requires a single unambiguous match or an explicit selected conversation. Unresolved multi-firm messages stay in the existing Replies ambiguity review; Today never invents a firm target. An older resolved conversation stays actionable while a newer message is ambiguous. Classified uncertain mail is identified as reply review; only deterministic human or human-confirmed replies are described as substantive. Classification confirmation is not an answer.

Answer evidence requires the existing verified manual-send effect in the same mailbox, firm and provider thread, with the matched contact among verified recipients, or a delivered reply request associated with the original message. Unrelated sent mail, automatic prospecting touches and internal forwards cannot clear a reply. Historical direct_send_manual markers do not record verified recipients and therefore cannot prove this answer; those conversations remain reviewable until authoritative current evidence resolves them.
