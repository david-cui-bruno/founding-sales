## Baseline and grading

The proposed context includes admitted originals, executed exact observations, and genuine server-owned coverage with their existing interpretation limits. Only the host mints markers. Prose may cite original-only, exact-only or mixed support; a reported header remains a report, query absence remains scoped absence, and unknown capture coverage remains unknown. Parse markers deterministically, reject unknown references, retain raw text, and manually assess factual clauses. No extraction generation, verifier generation, new frame framework or production answer-contract migration is needed to run this diagnostic. Production adoption would still require versioned result compatibility and existing whole-input access/deletion controls.

Correct the evaluator before measuring gains: neutralize questions that presuppose authenticated headers or complete channel history; supply accepted, supported reference answers including useful uncertainty; prove each can pass its graders. Anthropic recommends reference solutions, balanced cases, multiple trials and inspection of transcripts. ALCE evaluates fluency, correctness and citation quality separately; apply that separation here, adding explicit attribution and coverage checks. Marker membership is a format check, not entailment. Score responsiveness and useful uncertainty independently, and retain critical semantic errors even when prose improves. These are methodological recommendations, not imported reliability estimates. [Anthropic evaluation guidance](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents), [ALCE paper](https://aclanthology.org/2023.emnlp-main.398/).
