## Why no speculative TDD fix

No new deterministic implementation regression was reproduced. A frozen incorrect response replay can check handling, but it cannot prove a repaired model generation: supplying the same wrong response through a fake adapter remains wrong. The existing narrow unfinished-draft guard is independently retained. Broad regex filters for “coverage,” forced disclaimers or response rewrites would hide symptoms and reject supported statements without proving support. No such rule was added.

A generation-quality feedback loop requires an actual configured provider or a separately validated semantic evaluator. The retained artifacts provide exact failure witnesses, but are not that loop. Diagnosis therefore stops short of naming a prompt cause or claiming the neural failure fixed.
